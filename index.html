Home Depot R2-D2 conversion

HDR2D2 Build Hub

A remote-controlled R2-D2 with AstroPixels lights, mood sounds, a turning dome and powered feet. The FlySky receiver drives the feet directly. One dome board runs the lights, sound, holo servos and dome rotation.

Tools

Wiring Reference Every wire, power and signal, as a clickable diagram. Filter by circuit, search any terminal, print the wire schedule. Drive Visualizer Foot-drive layout: side, top and end views, a plate machining template and a kinematic calculator.

Build order

  1. Power — continuity, bucks, fuses
  2. Transmitter and receiver — bind, channels, output mode
  3. Drive — VESC inputs, settings, failsafe, wheels-up tests
  4. Dome electronics — firmware, lights, holo servos, radio link
  5. Sound — SD card, DFPlayer, volume
  6. Dome rotation — Hall sensor, dome servo, random dome

Source: github.com/mmcgeary/HDR2D2. This site shows the simplified-droid branch. The Teensy-based design is on the dual-board-wifi branch.
